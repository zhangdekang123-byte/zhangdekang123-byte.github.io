## 发布到 GitHub Pages
1. 登录 GitHub。
2. 新建一个 **Public（公开）** 仓库，例如 `personal-homepage`。
3. 将本文件夹里的全部文件上传到仓库根目录。
4. 打开仓库的 `Settings` → `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. Branch 选择 `main`，文件夹选择 `/ (root)`，保存。
7. 等待部署完成后，GitHub 会提供一个 `https://你的用户名.github.io/仓库名/` 形式的网址。
8. 打开网址检查图片、导航和 PDF 下载是否正常，再把网址提交给老师。

注意：这是公开网页，页面上的邮箱也会公开展示。如果不希望公开邮箱，可以把网页中的邮箱改成其他联系方式。
